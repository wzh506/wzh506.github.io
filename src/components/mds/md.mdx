# Researches


- **Integrated Navigation**: GNSS such as GPS, GLONASS, Galileo, and BeiDou are integrated with IMU to improve positioning accuracy.
- **Perception for AD**: SLAM, object detection, and BEV perception are applied to improve the perception of autonomous driving.
- **VLA4AD**: Vision-Language-Action model is a research project that aims to improve end-to-end accuracy of autonomous driving.
